# Harnish Kapoor — portfolio

A pastel sketchbook that scrolls sideways. This repo currently has **Chapter 01 — Home** (the landing page).

- **Stack:** Next.js 16 (App Router), React 19, TypeScript, CSS Modules. Hosted on Vercel, no backend.
- **Setup on a new machine:** see [SETUP.md](SETUP.md).

## How the page is built

- `src/components/Stage`: the page is one 1920×1080 artboard. `Stage` scales it to fit any window. At exactly 1920×1080 no transform is applied, so it renders identically to the export.
- `src/components/Landing`: the landing page, split into Header, Hero, ArchFrame, Badge, Footer and ChapterPeek. All values are in `Landing.module.css`.
- `src/app/fonts.css` + `public/fonts`: self-hosted copies of the exact Google Font files the design loads, generated by `npm run fonts`.
- `tests/`: Playwright end-to-end tests.

## Additions on top of the export

From the visual system: button hover (lilac, presses into its shadow), nav hover (dashed outline), keyboard focus rings and the slowly rotating badge (still when reduced motion is on).
